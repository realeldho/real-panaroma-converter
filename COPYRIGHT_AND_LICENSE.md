# Copyright and licensing checklist

This project is branded **Real Panorama Converter** and **real_eldho**. Branding and changes to the interface do not, by themselves, establish ownership of every line of source code.

Before publishing a license or saying that anyone may freely copy, modify, or republish this project:

1. Confirm whether the panorama-conversion implementation and other code were independently written or adapted from another project.
2. If code was adapted, check the original project's license and comply with its attribution and redistribution terms.
3. If the original project has no license or the permission is unclear, do not assume that public availability means reuse is permitted. Obtain permission or independently replace the adapted portions.
4. Once you have confirmed you have the rights, add the full text of the license you choose in a file named `LICENSE`.
5. Update the README's license section to match.

No open-source license is included in this kit intentionally. This is a practical checklist, not legal advice.
